# 甘露影视（LG Video）

甘露影视（LG Video）是 PointersMZX 出品的 Windows 桌面影视应用，集影视源解析浏览、本地视频播放与精雕播放器于一体。

## 功能

- **解析&浏览器**：内置多标签浏览器，顶行解析选项 + 第三方导航站点（默认空白，可自行添加），导航视频源一站直达
- **本地视频**：扫描本地视频文件成列表，点开即播
- **我的影视**：自建影视库——创建条目、管理剧集，网络链接与本地文件都能收
- **精雕播放器**：进度记忆与自动续播、倍速、A-B 循环、上一/下一集、全屏与全套快捷键；页面叠层与独立窗口两种形态
- **主题**：3 套内置（紫金黑/纯白/纯黑）+ 自定义取色，全界面液态玻璃质感——流动光影背景、磨砂玻璃面板与光泽微交互
- **更新**：GitHub 全球官方 / Gitee 国内镜像双渠道，应用内检查并安装
- **托盘**：关窗缩进托盘防误关，菜单直接跳页

左侧导航切换页面，快捷键 Ctrl+1~4 直达。

## 下载与安装

在 GitHub 仓库或 Gitee 镜像的 **Releases** 页面下载安装包：

| 版本 | 系统要求 |
|---|---|
| 常规版 | Win10 / Win11（64 位） |
| Win7 兼容版 | Win7（64 位） |

另有便携版（7z 压缩包）：解压即用，无需安装。

设置、影视库与播放进度自动保存在安装目录旁的 userData 文件夹，搬家时连同该文件夹一起移动即可带走全部数据。

## 应用内更新

设置 → **更新检查** 检查最新版本。双渠道可选：

- **全球官方渠道**：GitHub
- **国内镜像渠道**：Gitee

首次启动弹窗选择更新渠道，之后可在设置中随时切换；Win7 兼容版会自动下载对应资源。
